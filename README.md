### 🇬🇧 English

I fix electronic devices, mixers, and audio gear, and I love creating new things through hardware and music production. 

You can check out videos of my work in practice over on my [Instagram (@oxylabz)](https://www.instagram.com/oxylabz):

* 🎧 **Custom In-Ear Monitors (IEMs)** and audio projects with Knowles full-range driver.
* 🚴‍♂️ **Safety Bike LEDs:** A smart safety lighting system for bikes built with WS2812B and ATtiny85 using the NeoPixel library.
* 💡 **LED Headlamp:** A high-efficiency, 5W High CRI light focused on precision, great for micro-soldering, jewelry crafting, and medical/dental clinics (features magnetic pogo pins for comfort and portability).
* 💻 **Resistor Calculator:** I made a handy tool (Web and Executable) with an Ohmmeter simulation. It generates a horizontal Resistor Color Code Guide that helps you learn and visually memorize values with ease. *(Grab it on my GitHub repository!)* ❤️

### 🇧🇷 Português

Conserto equipamentos eletrônicos, mixers e audio gear, além de criar projetos em hardware e produção musical. 

No [Instagram (@oxylabz)](https://www.instagram.com/oxylabz), você pode ver vídeos de alguns deles na prática:
